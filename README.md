# HardGame

Game prototype built in Unity.

The repository contains the Unity project files, assets and project settings used for the current prototype. It is an experimental game project rather than a finished release.

## Environment

- Unity 6000.4.0f1
- C# / Unity project structure

## Repository layout

- `Assets/` — game assets and project code
- `Packages/` — Unity package configuration
- `ProjectSettings/` — Unity project settings
- `UnityDungeonPrototype/` — prototype-related project files

Open the project with Unity 6000.4.0f1 or a compatible editor version.
